## Description

libft is a foundational project at École 42 where students reimplement standard C library functions from scratch, without using the originals. The goal is to deeply understand how these functions work at a low level and to build a personal library reusable in future 42 projects.

This implementation covers character checks, string manipulation, memory functions, type conversion, output functions, and linked list operations.

## Installation

```bash
git clone https://github.com/Noemiegrau/libft.git
cd libft
make
```

This will compile the source files and create a `libft.a` library file you can link to your C programs.
